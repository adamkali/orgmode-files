** Evil Mode - Dvorak Navigation

*** Basic Movement
Your Emacs is configured with dvorak-friendly movement keys:

| Key | Standard | Dvorak Function |
|-----+----------+-----------------|
| =h= | ←        | Move left       |
| =t= | ↓        | Move down       |
| =n= | ↑        | Move up         |
| =s= | →        | Move right      |
| =k= | n        | Search next     |

*** Window Navigation (Ctrl + Movement)
| Key     | Function              |
|---------+-----------------------|
| =C-h=   | Move to left window   |
| =C-t=   | Move to window below  |
| =C-n=   | Move to window above  |
| =C-s=   | Move to right window  |

*** Uppercase Mappings
| Key | Function               |
|-----+------------------------|
| =T= | Join lines             |
| =N= | Help lookup (man)      |
| =S= | Move to bottom         |
| =K= | Search previous        |
