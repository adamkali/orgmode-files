# My Org-Mode Files

This repository contains my personal org-mode files including:

- **keybindings.org** - Emacs keybindings documentation
- **todos.org** - Personal task management
- **projects.org** - Project notes and tracking
- **notes.org** - General notes and documentation
- **inbox.org** - Quick capture inbox

## Usage

These files are synchronized with my Emacs configuration and can be cloned on any machine for consistency.

## Roam Directory

The `roam/` directory contains org-roam notes for knowledge management.
