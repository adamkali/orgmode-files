* Complete Org-Mode Tutorial

This comprehensive tutorial covers everything you need to know about using org-mode in your custom Emacs configuration.

** Getting Started - Basic Workflow

*** Step 1: Open Your Org Files
From emacsclient:
#+BEGIN_SRC bash
emacsclient -c ~/orgmode/todos.org
#+END_SRC

Or use your keybindings:
- *<space>ff* → Type "todos" → Enter

*** Step 2: Navigate Your Org Directory
Your setup has these files:
#+BEGIN_EXAMPLE
~/orgmode/
├── inbox.org         # 📥 Default captures
├── todos.org         # ✅ System todos
├── notes.org         # 📝 Quick notes
├── keybindings.org   # ⌨️  Keybinding reference
├── projects.org      # 🚀 Project tracking
└── roam/             # 🧠 Knowledge base (future)
#+END_EXAMPLE

** Core Org-Mode Operations

*** Creating and Managing Todos

**** Add a New Todo:
1. *Quick Capture*: =<space>oc t=
   - Type your todo
   - Press =C-c C-c= to save

2. *Direct Editing*:
   - Open =todos.org=
   - Type: =* TODO Learn advanced org-mode=
   - Press Enter

**** Todo States:
Your configured states: =TODO → IN-PROGRESS → WAITING → DONE/CANCELLED=

*Change states:*
- *<space>ot* - Cycles through states
- *C-c C-t* - Same thing (org-mode default)

**** Schedule and Deadlines:
- *<space>os* - Schedule item (=SCHEDULED: <2025-09-27 Fri>=)
- *<space>od* - Set deadline (=DEADLINE: <2025-09-30 Mon>=)
- *<space>op* - Set priority (=[#A]=, =[#B]=, =[#C]=)

*** The Org Agenda - Your Command Center

**** View Your Agenda:
*<space>oa* - Opens agenda view showing:
- Today's scheduled items
- Upcoming deadlines  
- All todos across files
- Weekly overview

**** Agenda Navigation:
- *t* - Change todo state
- *s* - Schedule item
- *d* - Set deadline
- *r* - Refresh agenda
- *q* - Quit agenda

** Capture System - Quick Notes

*** Capture Templates:
*<space>oc* + template key:

| Key | Template   | Goes To           | Use For       |
|-----+------------+-------------------+---------------|
| *t* | Todo       | =todos.org=       | System tasks  |
| *n* | Note       | =notes.org=       | Quick thoughts |
| *k* | Keybinding | =keybindings.org= | Document shortcuts |
| *p* | Project    | =projects.org=    | New projects  |

*** Capture Workflow:
1. *<space>oc t* (from anywhere in Emacs)
2. Type: "Set up automated backups"
3. *C-c C-c* to save
4. Item appears in =todos.org= under "System Todos"

** File Organization & Refiling

*** Refile Items:
*<space>oR* - Move current item to different file/heading
- Shows all headings across your org files
- Type to filter
- Enter to move

*** Archive Completed Items:
*<space>oA* - Archive completed todos
- Keeps files clean
- Preserves history

** Export & Sharing

*** Export Menu:
*<space>oe* opens export dispatcher:

| Key   | Format   | Output                            |
|-------+----------+-----------------------------------|
| *h h* | HTML     | Web-ready with syntax highlighting |
| *m m* | Markdown | GitHub-flavored markdown          |
| *l p* | PDF      | LaTeX → PDF                       |
| *a a* | ASCII    | Plain text                        |

*** Export Workflow:
1. Open any =.org= file
2. *<space>oe*
3. *h h* (for HTML)
4. Choose destination
5. Beautiful exported file with vapor theme colors!

** Pro Tips

*** Navigation:
- *C-c C-n/p* - Next/previous heading
- *C-c C-f/b* - Forward/backward same level
- *TAB* - Cycle heading visibility
- *S-TAB* - Cycle entire file visibility

*** Editing:
- *M-RET* - New heading/list item
- *M-LEFT/RIGHT* - Promote/demote heading
- *M-UP/DOWN* - Move heading up/down
- *C-c C-l* - Insert/edit links

*** Time Management:
- *C-c .* - Insert timestamp
- *C-c !* - Insert inactive timestamp
- *C-c C-x C-i* - Clock in (time tracking)
- *C-c C-x C-o* - Clock out
